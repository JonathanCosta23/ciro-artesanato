# Calculadora de Precificação e NFS-e

Projeto preparado para **Node.js 24**.

## Rodar localmente

```bash
node -v
npm start
```

Acesse:

```text
http://localhost:3000
```

## Desenvolvimento

```bash
npm run dev
```

O modo `dev` usa o `--watch` nativo do Node.js.

## Estrutura

- `index.html`: aplicação completa
- `server.js`: servidor HTTP sem dependências externas
- `package.json`: configuração do projeto
- `.nvmrc`: versão Node 24

## Observação fiscal

O PDF gerado pela aplicação é um espelho de conferência e não substitui uma NFS-e oficialmente autorizada pelo ambiente fiscal competente.
